毎朝、気になるニュースを自分のLINEに届けてくれるボットを、Google Apps Script（GAS）で作ってみた。この記事はその前半、**LINE側の準備編**だ。

先に結論を書いておく。やること自体は少ない。LINE公式アカウントを作って、「トークン」と「ユーザーID」という2つの文字列を手に入れれば終わりだ。

それなのに、けっこう迷った。原因は、**2つの管理画面を行ったり来たりすること**だった。

ボット本体の話は、次の記事で書く予定だ。

## まず知っておきたいこと：LINE Notifyはもう使えない

「GAS LINE 通知」で調べると、「LINE Notify」を使う記事がたくさん出てくる。トークンを1つ取るだけで送れる、とても手軽なサービスだった。

でも、**LINE Notifyは2025年3月に終わっている。** 古い記事の手順をなぞっても動かない。

今は、自分用のLINE公式アカウントを作って、そこから自分にメッセージを送る形になる。少し手間は増えるけれど、無料で使える。

## やったこと

| 手順 | どこでやるか | 何をするか |
|---|---|---|
| 1. ビジネスIDの登録 | account.line.biz | 普段のLINEでログインするだけ |
| 2. 公式アカウントを作る | 作成フォーム | 名前と業種を入れる |
| 3. Messaging APIをオンにする | LINE Official Account Manager | 管理者の名前（プロバイダー）を決める |
| 4. トークンを発行する | LINE Developers | 長い文字列が出てくる |
| 5. ユーザーIDを確認する | LINE Developers | Uで始まる文字列を控える |
| 6. 友だち追加する | スマホのLINE | 作った公式アカウントをQRコードで追加 |

かかった時間は、次の記事のGASの作業と合わせて**約3時間**。LINE側だけで何分かかったかは、計り忘れてしまった。次からは作業ごとに時間をメモしておこうと思う。

## お金はかからない

| 項目 | 費用 |
|---|---|
| LINE公式アカウント（無料プラン） | 0円 |
| メッセージの送信 | 無料プランは月200通まで |
| 今回の使い方 | 1日1回なので、月30通くらい。無料の範囲で収まる |

ちなみに、1回の送信で吹き出しを5つまでまとめて送れて、それでも「1通」と数えてくれる。テーマごとに吹き出しを分けても、通数は増えない。

作業中に、管理画面に「2026年10月1日から料金改定」というお知らせが出ていて、一瞬ドキッとした。調べてみると、変わったのは有料プランで使いすぎたときの料金で、無料プランには関係なかった。

## つまずき①　管理画面が英語だった

LINE Official Account Managerを開くと、なぜかメニューが英語で表示された。「Business profile settings」「Gain friends」といった感じだ。

調べて出てくる手順は日本語で書かれている。なので毎回、「友だちを増やす」は「Gain friends」のことだな、と**頭の中で翻訳しながら進める**ことになった。1回1回は小さな手間だけど、積み重なるとじわじわ時間を取られる。

## つまずき②　名前を変えると、7日間変えられない

公式アカウントを作ったあと、名前を変えたくなった。調べると、**一度変えると7日間は変えられない**らしい。打ち間違えても直せない。

気になったのは、「作ったばかりのアカウントでも、この7日ルールがかかるの？」という点。はっきり書いてあるページは見つからなかった。

試してみたら、**作ってすぐでも変えられた。** プロフィールの設定画面で、名前の横にある鉛筆マークから変更する。変えただけでは反映されず、右上の「Publish」を押す必要があった。

## つまずき③　友だち追加のQRコードが見つからない

作った公式アカウントを、自分のLINEで友だち追加しておかないと、メッセージは届かない。そのためのQRコードを探したけれど、なかなか見つからなかった。

QRコードがあったのは、次のどちらかだ。

| 画面 | 場所 |
|---|---|
| LINE Developers | 「Messaging API」タブの上の方 |
| LINE Official Account Manager | Home → Gain friends → Add friend tools |

「トークンはMessaging APIタブのいちばん下」と聞いていたので、同じタブの下の方ばかり見ていた。QRコードは、実は同じタブの上の方にあった。

## つまずき④　トークンがない画面で、トークンを探していた

いちばん時間を使ったのがここ。

LINE Official Account Managerにも「Messaging API」という画面がある。開くと「Channel ID」と「Channel secret」が並んでいる。てっきりこれがトークンだと思い込んで、AIに「これのことですか？」と聞いてしまった。

答えは「違います」。今回必要なトークンは、**そもそもこの画面にはない。** LINE Developersという、別のサイトで発行するものだった。

| 管理画面 | URL | 何をするところか |
|---|---|---|
| LINE Official Account Manager | manager.line.biz | 公式アカウントの見た目や配信の設定 |
| LINE Developers | developers.line.biz | トークンなど、プログラムで使う情報 |

この2つ、見た目がよく似ているうえに、どちらにも「Messaging API」という項目がある。迷うのも無理はないと思う。**左上のロゴかURLを見て、今どっちにいるかを確かめる**ようにしてから、迷わなくなった。

## つまずき⑤　「ID」が2つある

LINE Developersの「Basic settings」タブには、IDが2つ並んでいる。

| 項目 | 場所 | 中身 | 今回使う？ |
|---|---|---|---|
| Channel ID | タブの上の方 | 10桁くらいの数字 | 使わない |
| Your user ID | タブのいちばん下 | Uで始まる33文字 | 使う |

送り先として使うのは「Your user ID」のほう。どちらも「ID」なので、うっかり取り違えそうになる。LINEアプリで自分で決める「LINE ID」とも、また別物だ。

トークンとユーザーIDは、パスワードのようなもの。人に見せたり、スクリーンショットに写したりしないように気をつけたい。

## やってみて分かったこと

**やることが少なくても、管理画面が2つあると迷う。** 操作はボタンを押して文字列をコピーするだけ。時間がかかったのは、毎回「これはどっちの画面でやるんだっけ？」と探すことだった。CloudflareとGitHubでサイトを公開したときも、まったく同じだった（「[AstroサイトをCloudflareで公開するのに1時間30分かかった話](/blog/astro-cloudflare-deploy)」）。

**似た名前のものが、別の場所に別の意味で置いてある。** 「Messaging API」は両方の画面にあって、中身が違う。IDも2つある。初めて触る人は名前を頼りに探すので、ここはほぼ確実に引っかかると思う。

**手順と画面の言語が違うだけで、ぐっと遅くなる。** もし外注先に手順書を作ってもらうなら、実際の画面の言語に合わせてもらえると、受け取る側はかなり楽になるはずだ。
